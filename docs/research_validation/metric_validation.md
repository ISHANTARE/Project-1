## 1. Executive Summary

Evaluation of code-mixed machine translation and lexical borrowing preservation requires rigorous mathematical metrics capable of distinguishing **token classification accuracy** (internal gating) from **generative text quality** (end-to-end neural output).

This document establishes the formal definitions, implementation specifications, and mathematical sanity checks for all metrics reported across the LAPS benchmark suite. It documents the resolution of historical methodological flaws—specifically the misattribution of internal classification metrics to end-to-end systems and the qualification of lexical leakage proxies.

---

## 2. Token-Level Preservation Classifier Metrics

When evaluating the internal decision engine of LAPS (and rule-based lexical filters):

Let $\mathcal{C}$ be the set of candidate English loanword tokens identified in an input utterance. Each candidate $t \in \mathcal{C}$ has a binary ground-truth label $y_t \in \{0, 1\}$ (where $1$ denotes that the borrowing should be preserved as an English loanword, and $0$ denotes assimilation or replacement) and a model prediction $\hat{y}_t \in \{0, 1\}$.

### Confusion Matrix Definitions
- **True Positive ($\text{TP}$)**: $\hat{y}_t = 1 \land y_t = 1$ (Borrowing correctly designated for preservation)
- **False Positive ($\text{FP}$)**: $\hat{y}_t = 1 \land y_t = 0$ (Hindi matrix term incorrectly marked for preservation)
- **False Negative ($\text{FN}$)**: $\hat{y}_t = 0 \land y_t = 1$ (Borrowing incorrectly omitted from preservation constraints)
- **True Negative ($\text{TN}$)**: $\hat{y}_t = 0 \land y_t = 0$ (Hindi matrix term correctly allowed to be translated)

$$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}, \quad \text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}$$

$$\text{Micro-F1} = \frac{2 \cdot \text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}} = \frac{2 \cdot \text{TP}}{2 \cdot \text{TP} + \text{FP} + \text{FN}}$$

$$\text{Accuracy} = \frac{\text{TP} + \text{TN}}{\text{TP} + \text{FP} + \text{FN} + \text{TN}}$$

### Uncertainty Rate
Tokens falling within the register-adaptive borderline interval $[T_{\text{lower}}(\text{reg}), T_{\text{upper}}(\text{reg})]$:
$$\text{Uncertainty Rate} = \frac{|\{t \in \mathcal{C} \mid \text{decision}(t) = \text{UNCERTAIN}\}|}{|\mathcal{C}|}$$

## 3. Generative Output Metrics

### 3.1. Over-Translation Error Rate (OTER)

**Definition:** The fraction of gold preserved loanwords that the generation model translated or omitted from the final target sentence.

Let $\mathcal{G}_i = \{w \in \text{tokens}(s_i) \mid y_w = 1\}$ be the set of ground-truth preserved loanwords for sentence $i$.  
Let $\mathcal{W}_i = \text{tokens}(\hat{y}_i)$ be the set of surface word tokens produced in the generated output text.

$$\text{OTER}(s_i) = \begin{cases} 
0.0 & \text{if } |\mathcal{G}_i| = 0 \\
1.0 - \frac{|\mathcal{G}_i \cap \mathcal{W}_i|}{|\mathcal{G}_i|} & \text{if } |\mathcal{G}_i| > 0
\end{cases}$$

For a corpus of $N$ utterances:
$$\text{Macro-OTER} = \frac{1}{N} \sum_{i=1}^N \text{OTER}(s_i)$$

**Directionality:** Lower is better ($\downarrow$). A score of $0.0$ indicates perfect loanword retention.

### 3.2. Output Retention Recall, Precision, and Output F1

Unlike classifier metrics which operate on pre-extracted tokens, **Output Metrics** evaluate the actual surface string generated by the neural decoder:

$$\text{Output Recall} = \frac{|\mathcal{G}_i \cap \mathcal{W}_i|}{|\mathcal{G}_i| + \epsilon}$$

$$\text{Output Precision} = \frac{|\mathcal{G}_i \cap \mathcal{W}_i|}{|\mathcal{W}_i \cap \mathcal{V}_{\text{loan}}| + \epsilon}$$
*(where $\mathcal{V}_{\text{loan}}$ represents candidate borrowings identified in the generation output).*

$$\text{Output F1} = \frac{2 \cdot \text{Output Precision} \cdot \text{Output Recall}}{\text{Output Precision} + \text{Output Recall} + \epsilon}$$

**Directionality:** Higher is better ($\uparrow$).

## 4. Under-Translation Error Rate (UTER) & Lexical Leakage Proxy

### 4.1. Strict Gold UTER Disqualification

Under-Translation Error Rate (UTER) is formally defined as the rate at which matrix Hindi words are improperly copied verbatim into the target English translation without being translated.

$$\text{Gold UTER} = \frac{|\text{Hindi Matrix Words Copied Un-translated}|}{|\text{Total Gold Hindi Matrix Words}|}$$

> [!CAUTION]
> **Audit Finding:** The evaluation datasets (`gold_corpus.json`, `test_split.json`) annotate gold labels ($y \in \{0, 1\}$) **only for candidate English loanwords**; they do **not** provide full-utterance word-level Language Identification (LID) or token alignment for the non-candidate Hindi matrix words.
>
> Consequently, **Strict Gold UTER cannot be mathematically computed from the current dataset without fabricating ground-truth annotations.** Any paper reporting "Gold UTER = 0.0%" from these files is factually incorrect.

### 4.2. Operational Lexical Proxy: Matrix Hindi Leakage Rate

In accordance with scientific integrity guidelines, the benchmark reports a **Matrix Hindi Leakage Proxy**:

$$\text{Leakage Proxy} = \frac{|\mathcal{W}_{\text{gen}} \cap \mathcal{V}_{\text{Devanagari/RomanHindi}}|}{|\mathcal{W}_{\text{gen}}|}$$

- **Status in Tables:** Strictly annotated as `N/A (Lacks Gold Full-Utterance LID)`.
- **Heuristic Estimate:** Across real neural outputs, standard NMT models map Romanized Hinglish phonetic tokens to English phonological approximations, resulting in a matrix leakage proxy of $0.0123$ to $0.0157$, while surrogate templates display $0.8442$ due to incomplete dictionary coverage.

## 5. Machine Translation Quality Metrics

Standard surface matching metrics are computed using standardized reference implementations to ensure cross-paper reproducibility.

### 5.1. SacreBLEU 2.6.0

Corpus-level and sentence-level BLEU are computed using SacreBLEU v2.6.0:
- **Reference Count:** Single reference (`nrefs:1`)
- **Case Sensitivity:** Mixed case preserved (`case:mixed`)
- **Tokenization:** Standard 13a tokenization (`tok:13a`)
- **Smoothing:** Exponential smoothing (`smooth:exp`)

**Signature:**
```text
nrefs:1|case:mixed|eff:no|tok:13a|smooth:exp|version:2.6.0
```

### 5.2. chrF++

chrF++ extends character n-gram F-score with word bi-grams to provide balanced evaluation for morphologically rich or code-mixed text:
- **Character n-gram order:** 6
- **Word n-gram order:** 2
- **Beta parameter:** 2.0 (recall-weighted)

**Signature:**
```text
nrefs:1|case:mixed|eff:no|nc:6|nw:2|space:no|version:2.6.0
```

## 6. Resolution of Methodological Flaws

| Historical Flaw | Root Cause | Audited Scientific Resolution |
| :--- | :--- | :--- |
| **Category Error on Baseline F1** | `Unconstrained NMT` was scored 0.0 on classifier F1 because it lacks an internal classifier. | Classifier metrics for Unconstrained NMT are explicitly marked **`N/A (No Internal Classifier)`**. Output-level loanword retention is credited fairly via Output F1 and OTER. |
| **Spurious 0.0% UTER** | Script hard-coded UTER to 0.0 without verifying token-level matrix ground truth. | Qualified as `N/A (Lacks Gold Full-Utterance LID)` with transparent documentation of dataset annotation limitations. |
| **Surrogate Generation Conflation** | Regex/template mock was reported as live neural translation. | Benchmarks are now partitioned into **Live Neural Generation (`Helsinki-NLP/opus-mt-hi-en` on GPU)** and **Deterministic Surrogate Baseline**, with explicit execution telemetry. |
